# COA Cleanup — GL 1121, 1122, 1123 — Design Spec

**Issue:** #13 — Asset-side savings accounts 1121–1123 are seeded but never posted to. They duplicate the correct liability-side accounts 2111–2113.

**Goal:** Mark the three accounts as non-postable in `SaccoCoaSeeder` so they no longer appear as valid posting targets in the UI.

**Architecture:** Single seeder edit. No service or migration changes needed.

---

## Problem

`SaccoCoaSeeder` seeds three accounts under GL group `1120` (Member Savings Control):

| GL Code | Name | Type | Normal Balance |
|---------|------|------|---------------|
| 1121 | Mandatory Savings – Members | ASSET | DR |
| 1122 | Voluntary Savings – Members | ASSET | DR |
| 1123 | Fixed Deposit – Members | ASSET | DR |

These are DR-normal-balance asset accounts. Member savings should be recorded as **liabilities** (money owed to members), not assets. The correct posting accounts are the CR-normal-balance liability accounts:

| GL Code | Name | Type | Normal Balance |
|---------|------|------|---------------|
| 2111 | Mandatory Savings Deposits | LIABILITY | CR |
| 2112 | Voluntary Savings Deposits | LIABILITY | CR |
| 2113 | Fixed Deposits | LIABILITY | CR |

No current service posts to 1121–1123. Leaving them as `is_postable => true` risks accidental manual journal entries against them.

---

## Fix

In `SaccoCoaSeeder::getSaccoUgandaAccounts()`, change the three rows:

**Before:**
```php
['gl_code' => '1121', 'name' => 'Mandatory Savings – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => true],
['gl_code' => '1122', 'name' => 'Voluntary Savings – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => true],
['gl_code' => '1123', 'name' => 'Fixed Deposit – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => true],
```

**After:**
```php
['gl_code' => '1121', 'name' => 'Mandatory Savings – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => false],
['gl_code' => '1122', 'name' => 'Voluntary Savings – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => false],
['gl_code' => '1123', 'name' => 'Fixed Deposit – Members', 'account_type' => 'ASSET', 'account_subtype' => 'Member Savings', 'normal_balance' => 'DR', 'level' => 4, 'is_control' => false, 'is_postable' => false],
```

The accounts remain in the COA for audit history but are hidden from manual posting dropdowns. No GL data is deleted.
